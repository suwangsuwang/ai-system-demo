# AI System Demo

An AI system demonstration project with Spring Boot backend.

## Project Structure

```
ai-system-demo/
├── backend/        # Spring Boot application
├── deploy/
│   ├── docker-compose.yml
│   └── nginx/      # Nginx configuration
├── scripts/        # Utility scripts
└── README.md
```

## Getting Started

```bash
# Start all services
docker-compose -f deploy/docker-compose.yml up -d
```
